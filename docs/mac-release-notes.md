BooBoo & Moo Krata for Windows and macOS — no Python installation or Terminal commands required.

Both pets now have 25 distinct poses, correctly mirrored left/right movement, and longer natural rest/play cycles. This update uses a native floating Mac window that follows Spaces and prepares the artwork before showing the window; a diagnostic alert appears if startup fails.

1. Download `BooBoo-macOS-Apple-Silicon.zip` for an M-series Mac, or `BooBoo-macOS-Intel.zip` for an Intel Mac.
2. Unzip the download and double-click `BooBoo.app`. BooBoo starts on the desktop; Control-click the pet to open its menu.

Windows users: download `BooBoo-Windows.zip`, unzip it, and double-click `BooBoo/BooBoo.exe`.

This free build is ad-hoc signed and has not been notarized by Apple. If macOS blocks the first launch, open **System Settings → Privacy & Security → Open Anyway**, then confirm **Open**. After that, double-click normally. [Apple's instructions](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)
