# Cute Desktop Pet — Multi-Platform Release 🐾

แอปสัตว์เลี้ยงบนเดสก์ท็อปสำหรับ Windows และ macOS ทุกรุ่น (ไม่ต้องติดตั้ง Python หรือเปิด Terminal)

### 📥 เลือกรุ่นดาวน์โหลดให้ตรงกับอุปกรณ์ของคุณ:

1. **🪟 Windows (Windows 10, Windows 11 ทุกรุ่น):**
   - ดาวน์โหลด **`CuteDesktopPet-Windows.zip`**
   - แตกไฟล์ ZIP แล้วดับเบิลคลิก **`MooKrata.exe`** (ลูกหมาเบอร์นีส) หรือ **`BooBoo.exe`** (กระต่ายหูตก) เล่นได้ทันที!

2. **🍏 Mac ชิป Apple Silicon (M1, M2, M3, M4 ทุกรุ่น):**
   - ดาวน์โหลด **`CuteDesktopPet-macOS-Apple-Silicon.zip`**
   - แตกไฟล์ ZIP แล้วดับเบิลคลิก **`BooBoo.app`**
   - *(หาก macOS บล็อกการเปิดครั้งแรก ให้ไปที่ System Settings → Privacy & Security → Open Anyway)*

3. **🍏 Mac ชิป Intel (MacBook, iMac, Mac mini รุ่นเก่า):**
   - ดาวน์โหลด **`CuteDesktopPet-macOS-Intel.zip`**
   - แตกไฟล์ ZIP แล้วดับเบิลคลิก **`BooBoo.app`**

---

### ✨ ฟีเจอร์เด่น:
- **Moo Krata (หมูกระทะ):** ลูกหมาพันธุ์เบอร์นีส เมาน์เทนด็อก พร้อมชุดแอนิเมชันคุณภาพสูงระดับ HD วิ่ง กระโดด หมอบชวนเล่น นอนหลับ ขอบโปร่งใส 100%
- **BooBoo:** กระต่ายหูตกสีขาวสุดน่ารัก
- คลิกขวาที่ตัวละครเพื่อสั่งกระโดด, ปรับความเร็ว, เปลี่ยนตัวละคร หรือสั่งพักผ่อนได้ตลอดเวลา
